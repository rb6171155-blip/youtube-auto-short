YouTube Auto Short

YouTube Auto Short は、作成したショート動画を自身のYouTubeチャンネルへ自動投稿するための個人用オートメーションツールです。

アプリケーションの概要

本アプリケーションは、YouTube Data API v3 を使用して、指定された動画ファイルを自身のYouTubeチャンネルに限定公開または予約投稿としてアップロードします。

アクセスする権限（スコープ）

本アプリは以下のGoogle OAuthスコープを利用します：

  • https://www.googleapis.com/auth/youtube.upload: 動画のアップロードおよびメタデータ（タイトル・説明等）の設定のみに使用します。

プライバシーポリシー

本アプリケーション（YouTube Auto Short）におけるユーザー情報の取り扱いについて以下に定めます。

1. 収集する情報

本アプリは、YouTube Data API の実行に必要なOAuth認証情報（アクセストークンおよびリフレッシュトークン）のみをローカル環境およびGitHub Secrets上で暗号化して保持します。その他の個人情報やブラウザ履歴などを収集することはありません。

2. 情報の利用目的

取得した認証情報は、ユーザー本人のYouTubeチャンネルへ動画をアップロードする自動処理の実行目的のみに使用されます。

3. データの共有および第三者への提供

収集した認証情報およびデータを、外部の第三者と共有、販売、または開示することは一切ありません。

4. データの管理と保管

認証情報は安全なCI/CD環境（GitHub Secrets）およびローカル環境でのみ管理され、外部からの不正アクセスを防止します。

5. Google API サービスのユーザーデータポリシーへの準拠

本アプリによるGoogle APIから取得した情報の使用および他のアプリへの転送は、制限事項要件を含め、Google API サービスのユーザーデータポリシーに準拠します。
